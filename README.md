# PiArtNetMedia

## Idee

Raspberry PI als ArtNet Medien Server. Über einen USB-Stick sollen Bilder und Videos in jeweils einem Ordner zur Verfügung gestellt werden. Ein Python scipt sorgen dann dafür das jeweils eins angezeigt wird. Hierfür sollen auf einem HDMI Ausgang Bilder auf dem anderen Videos ausgegeben werden.
 Das skirpt bekommt einen Artnet Input welcher entscheidet was angezeigt wird. Für Videos langfristig auch mehr Parameter.
